### Code and Reproducibility

The analysis was implemented in **Python**.

The code used to generate the indicator results is publicly available at:

[github.com/FedericoTartarini/paper-lancet-countdown-global](https://github.com/FedericoTartarini/paper-lancet-countdown-global)

Users wishing to reproduce the analysis should first obtain the required datasets described in Methods and then follow the instructions provided in the repository's `README.md` file.

The repository contains detailed instructions for setting up the analytical environment, preparing the input data, and running the Python workflow to reproduce the results.
