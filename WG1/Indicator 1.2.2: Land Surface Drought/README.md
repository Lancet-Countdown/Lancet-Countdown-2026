## Brief description of the indicator
This indicator tracks the proportion of global land area affected by unusually severe droughts using the 6-month Standardised Precipitation Evapotranspiration Index (SPEI6), which captures drought intensity and duration by comparing precipitation against potential evapotranspiration. Using ERA5-Land data from 1980 onwards, droughts are classified against a 1981–2020 baseline, and the indicator reports land area exposed to excess extreme and exceptional drought events each year.
