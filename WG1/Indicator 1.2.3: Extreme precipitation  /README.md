## Brief description of the indicator
The indicator uses ERA5-Land daily precipitation data to identify extreme and very extreme rainfall events. For each gridcell, "extreme" days exceed the 99.945th percentile and "very extreme" days exceed the 99.973rd percentile, using a 1961–1990 reference period. Each year, gridcells are flagged as affected or unaffected by these events, and the percentage of global land area affected is calculated. The indicator then compares 2016–2025 vs. 2006–2015, and 2006–2015 vs. 1996–2005 to assess whether affected land area is changing.
