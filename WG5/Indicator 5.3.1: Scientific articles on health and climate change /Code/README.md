## Code and Data Availability

All analytical code for this indicator is openly available through the **PIK GitLab repository**:

- [PIK GitLab – Climate Health Map](https://gitlab.pik-potsdam.de/mcc-apsis/living-evidence-maps/climate-health-map)

The **raw data** used for this indicator are openly available on Zenodo:

- [Zenodo – Raw Data](https://zenodo.org/records/19475919)

An **interactive version of the dataset and results** is also available through the Climate Literature platform:

- [Climate Literature](https://climateliterature.org)
