# Additional Analysis (Appendix Outputs)

## Purpose

This folder is used to store **additional analysis, figures, and tables** that support the indicator but are not included in the main text of the report.

---

## What to include

Authors can upload:

- Supplementary figures  
- Additional tables  
- Extended results  
- Any supporting outputs  

---

## File Organisation

Please organise files clearly, for example:
```text
outputs/
├── figure_1.png
├── figure_2.png
├── table_1.xlsx
└── additional_results.csv
```
## Guidelines
 
- Use clear and consistent file names  
- Ensure figures are publication quality  
- Include captions or descriptions where needed  

---

## Notes

- These materials will be used for the **appendix/supplementary section**  
- Keep this folder clean and well-organised  
- Do not duplicate files from the main analysis  

---

For questions, contact your Working Group lead, fellows or repository maintainer.
