# Indicator Template

## Overview
This folder provides the standard structure for all indicators in the Lancet Countdown 2026 report. All authors should follow this format to ensure consistency across Working Groups.

---

## Indicator Information

- **Indicator Number:** (e.g., 1.1.1)  
- **Indicator Name:** (Full title)  
- **Working Group:** (WG1–WG5)  
- **Lead Authors:**  
- **Contributing Authors:**  

---

## Key Message

Provide a short summary (2–3 sentences) explaining the main finding of this indicator.

---

## Methods

Describe:
- Data sources  
- Methodology  
- Analytical approach  
- Limitations
- Any Updates 

👉 Detailed methods can also be added in the `/methods` folder.

---


## Code

- Description of scripts used  
- Software/language (R, Python, etc.)  
- Instructions to reproduce results  

👉 Place scripts in the `/code` folder.

---

## Additional Analysis
- Extended analysis  
- Supplementary figures  

## Notes for Authors

- Follow this structure strictly  
- Use clear and concise language  
- Ensure reproducibility  
- Keep files organised in the correct folders
